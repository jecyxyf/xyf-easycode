# EasyCode 网页部署

你作为优秀且资深的应用部署工程师,帮助用户部署软件架构 HTML 网页。

目标目录为 `<project>/docs/xyf-easycode/`，下文简称 `<workspace>`。

**部署前只检查下方目录结构。** 结构符合就报告“已部署，跳过”，立即结束本技能，不再执行后续步骤。

## 执行步骤

| 步骤        | 要求                                                                                                                                                                  |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1. 检查现有环境 | 只确认下方列出的文件和目录是否存在，不检查子目录内部文件或文件内容。结构符合则跳过；有缺失才补齐，保留已有配置和定制。额外文件不影响判断。                                                                                               |
| 2. 复制或补齐  | 新目录完整复制；已有目录只复制缺失文件。保留已有 `software_architecture.js`、`language.js`、组件定制和额外文件。文件与目录类型冲突时报告冲突，不删除或覆盖。需要替换现有文件时，先取得该替换范围的明确授权。                                          |
| 3. 设置语言 | 先确认网页语言，已确认则沿用。中文用 `html/language_zh.js`，英文用 `html/language_eng.js`；其他语言由当前 Agent 翻译。结果保存为 `<workspace>/html/language.js`，保留全部消息键、占位符和配置格式，设置对应的 `locale`、`name`。已有配置符合要求则保留。 |
| 4. 核对结果   | 检查来源清单中的文件均已存在，核对本次复制文件的内容与来源一致；按用户要求调整的语言文件另行检查。检查目标 `index.html` 的本地资源引用均能找到对应文件。已有文件内容不同不代表可以覆盖。                                                                 |
| 5. 交付     | 给出目标目录、`index.html` 的完整路径、复制或跳过情况、实际检查结果。文件完整且无需修改时报告“已部署，跳过复制”。用户可双击入口打开；有浏览器能力时可验证加载，未实际打开时明确说明。                                                                  |

部署后的主要文件如下，其他来源文件也要完整保留：

```text
docs/xyf-easycode/html/          # 项目的架构网页目录
├── index.html                 # 网页入口，双击打开
├── software_architecture.js   # 项目架构数据：分层、模块、接口和依赖
├── language.js                # 当前界面的语言和文字配置
├── assert/                    # 网页组件、样式和交互逻辑
├── module/                    # 画布、模块卡片和分层的模板
└── references/                # 供 Agent 阅读的参考资料
    └── architecture-data.jsonc # 架构数据的字段说明、填写规则和完整示例
```

网页自动加载同目录的语言和数据文件，无需 Node.js、构建命令或服务器。首次部署的数据文件是空白模板，不代表已有项目需求；本技能不生成业务架构，也不自动迁移旧项目配置。

保存时，支持本地文件写入的浏览器需要用户首次选择数据文件并授权；不支持时下载 JS 副本，替换原文件后刷新。详细用法见[网页说明](html/README.md)。部署完成后结束，不自动开始设计或编码。
